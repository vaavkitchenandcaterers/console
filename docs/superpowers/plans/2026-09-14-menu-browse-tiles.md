# Menu Page Browse Tiles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the two inline link sentences at the foot of the `/menu/` explorer ("Prefer to read the whole list? …" and "Planning a particular function? …") with the site's described-tile pattern, in two labelled groups, keeping all seven links.

**Architecture:** `/menu/` (`site/menu/index.html`) is hand-maintained; its `.menu-browse` block sits inside `section#menu` after the explorer card. Every other page links these destinations as `.menu-tile` tiles (the "Keep exploring" rows generated by `tools/menu-page-template.mjs`, and the "Other occasions we cater" rows on About, Contact and Corporate). This plan reuses that exact markup and copy: category tiles from `CATEGORY_META[c].h1` + `CATEGORY_BLURB[c]`, occasion tiles from `OCCASION_META[o]`, service tiles from `SERVICE_TILES`. A test pins the hub's tiles to those template constants so the copy cannot drift.

**Tech Stack:** Static HTML/CSS, Vitest 3 (`environment: 'node'`), Node 22, Python 3.12 Playwright.

**Source review (14 Sep 2026, deploy preview 11, 375 / 1280 / 1920px):** all seven links return 200, but each is a 25px-tall inline link; at 375px "puja or homam" wraps into two pieces; seven destinations share two dense muted 15px sentences (the first repeats "every" four times); the link reads "puja or homam" where the page and every other tile say "Puja, homam & temple catering"; and `/menu/` is the only page still using sentences for these destinations. The owner approved the tile replacement.

```js
describe('/menu/ browse tiles', () => {
  const hub = readFileSync(new URL('./menu/index.html', import.meta.url), 'utf8');
  const browse = hub.match(/<div class="menu-browse">[\s\S]*?\n    <\/div>/)?.[0];
  const tile = (href, label, desc) =>
    `<li><a class="menu-tile" href="${href}"><span class="mt-label">${escapeHtml(label)}</span>` +
    `<span class="mt-desc">${escapeHtml(desc)}</span><span class="mt-go" aria-hidden="true">→</span></a></li>`;

  it('replaces the inline link sentences with two labelled groups of tiles', () => {
    // The sentences held seven 25px links; "puja or homam" split across two lines on a phone.
    expect(browse, 'no .menu-browse block').toBeTruthy();
    expect(hub).not.toContain('menu-flat-links');
    expect(browse.match(/<h2 class="browse-h">[^<]+<\/h2>/g)).toEqual([
      '<h2 class="browse-h">Every set, every dish</h2>',
      '<h2 class="browse-h">Planning a function?</h2>'
    ]);
  });

  it('links every category, occasion and service page in the words the other pages use', () => {
    const expected = [
      ...ORDER.map(c => tile(`/menu/${c}/`, CATEGORY_META[c].h1, CATEGORY_BLURB[c])),
      ...OCCASIONS.map(o => tile(`/menu/${o}/`, `${OCCASION_META[o].label} menus`, OCCASION_META[o].blurb)),
      ...SERVICE_TILES.map(t => tile(t.href, t.label, t.blurb))
    ];
    const got = [...browse.matchAll(/<li><a class="menu-tile"[\s\S]*?<\/li>/g)].map(m => m[0]);
    expect(got).toEqual(expected);
  });

  it('styles the group headings and drops the old sentence styles', () => {
    const css = readFileSync(new URL('./style.css', import.meta.url), 'utf8');
    expect(css).not.toContain('.menu-flat-links');
    expect(css).toContain('.menu-browse .browse-h{font-size:1.5rem;color:var(--green-deep);margin:0 0 16px}');
    expect(css).toContain('.menu-browse .menu-tiles + .browse-h{margin-top:32px}');
  });
});
```
